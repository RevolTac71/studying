# 데이터·금융 학습 저장소

Python과 금융 데이터 분석을 공부하며 작성한 실습 코드와 개인 포트폴리오 웹 페이지를 모아둔 저장소입니다.

## 구성

- `index.html`, `portfolio.js`, `myStyle.css`: 개인 포트폴리오 웹 페이지 관련 파일
- `projects/MonteCarlo/`: 몬테카를로 관련 실습
- `projects/StockAnalysis/`: 주식 분석 관련 실습
- `python/`: Python 및 금융 데이터 실습 파일
- `packaged/`: 별도 Python 앱 및 의존성 파일
- `Images/`: 웹 페이지와 실습에 사용하는 이미지

각 실습의 의존성은 해당 폴더의 `requirements.txt`를 확인하세요. 오래된 실습 코드는 현재 라이브러리나 외부 데이터 서비스와 호환되지 않을 수 있으며, 이 문서 작성 과정에서 실행 여부는 검증하지 않았습니다.
